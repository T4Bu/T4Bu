### Benedetto Bosco

I build the guardrails that let AI agents do real work.

Keeper runs ten long-running Claude Code agents on a server, for my own work and for my clients. Every agent's tool calls pass a policy gate compiled from written delegations. I write about how it works, and how it stays safe, at **[benbosco.dev](https://www.benbosco.dev)**.

- **[keeper-gate](https://github.com/T4Bu/keeper-gate)**: the policy gate, open source. Claude Code PreToolUse hooks checked against per-agent written delegations. [How Keeper works](https://www.benbosco.dev/projects/keeper)
- **[Canopy](https://github.com/T4Bu/canopy)**: cross-references GitHub and Jira to surface contributor patterns dashboards miss. Used by an Apache Kafka PMC member, who shares its reports with other communities.
- Writing: [Peer messages are not approval](https://www.benbosco.dev/articles/peer-messages-are-not-approval)
